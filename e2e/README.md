# Визуальные снапшот-тесты (Playwright) — PLAN-HARDENING.md 5.4

Ловят непреднамеренные изменения вёрстки ключевого UI. Запускаются против **только**
фронтенд-dev-сервера (`npm run frontend:dev`) — бэкенд/авторизация не нужны: каталог —
маршрут по умолчанию и падает на демо-данные, когда API недоступен.

## Команды

```bash
npm run test:visual          # прогнать снапшоты (падает при расхождении вёрстки)
npm run test:visual:update   # перегенерировать эталоны (после намеренного изменения UI)
```

Playwright сам поднимет `frontend:dev` (или переиспользует запущенный).

## Эталоны

Лежат в `e2e/__screenshots__/<имя>-<platform>.png` и закоммичены в git.

**Важно:** эталоны привязаны к ОС (рендер шрифтов отличается Windows/Linux). Суффикс
`-<platform>` (`win32`, `linux`, `darwin`) даёт каждой ОС свой эталон. При первом прогоне
на другой ОС (например, Linux-CI) запустите `npm run test:visual:update`, чтобы создать
эталон для неё, и закоммитьте его.

## Что снимаем

Только детерминированный UI (тулбар фильтров каталога, открытый кастомный дропдаун) —
без дат/счётчиков, чтобы эталоны были стабильными. Список товаров намеренно исключён.
Добавляя новый снапшот, выбирайте область без изменяющихся данных или маскируйте её
(`mask: [...]`).

## Админ-страницы (мок API через `page.route`)

`admin-dashboard.spec.ts` снимает дашборд (`/app/dashboard`), который доступен только роли
admin и тянет ~7 эндпоинтов. Чтобы прогон оставался самодостаточным (без бэкенда):

- `**/api/**` мокается пустым `{}` — у всех полей схем дашборда есть дефолты, поэтому ответ
  `{}` рендерит детерминированный «все нули» дашборд, одинаковый в loading- и loaded-состоянии;
- `**/api/session` отдаёт `{ authenticated: true, role: "admin" }`, иначе страница недоступна;
- `**/api/notifications/stream` (SSE) — `route.abort()`, у него нет видимого UI здесь.

Переход на `/app/dashboard` делается кликом по ссылке в сайдбаре (SPA `pushState`), а не
`page.goto`: dev-сервер Vite отдаёт SPA только под базой `/app-modern/`, а роутинг приложения
ждёт «голый» путь `/app/...` (как в продакшене, где express отдаёт `/app/*` напрямую).
