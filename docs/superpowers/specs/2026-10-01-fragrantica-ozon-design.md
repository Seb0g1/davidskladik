# Фрагрантика → Ozon: каталог ароматов и создание карточки в одно нажатие

Дата: 2026-10-01. Согласовано с владельцем в чате («ок на всё»).

## Цель
В davidsklad появляется страница «Фрагрантика» со всеми ароматами fragrantica.ru (разрешение Фрагрантики есть).
Сотрудник находит аромат, нажимает «Добавить на Ozon», в форме проверяет/дозаполняет характеристики
(бренд и артикул подставляются сами, объём и цена — вручную) и создаёт карточку в кабинете Ozon.
Фото флакона обрабатывается parfumdeclaration (премиум-фон + ИИ-увеличение), вторым фото идёт
картинка «Пирамида аромата» с нотами (рендерит parfumdeclaration), в конец карточки parfumdeclaration
сам добавляет «Секреты нанесения» и «Спасибо» (существующая функция «Фото в конце», ежечасно).
Дальше карточка живёт по обычной схеме: импорт с Ozon, привязка к поставщику, остатки.

## Решения
- Каталог: обход `/designers-1..N/` → страницы брендов (список ароматов с полом и годом) → страницы
  ароматов (детали) в фоне на worker, 2 запроса/с (`FRAGRANTICA_CRAWL_RPS`), бэкофф на 403/429/5xx,
  выключатель `FRAGRANTICA_CRAWL_ENABLED`. Любой аромат можно подтянуть сразу по ссылке/при открытии.
- Хранение: таблицы PG без prisma-миграции (lazy `CREATE TABLE IF NOT EXISTS`):
  `fragrantica_brands`, `fragrantica_perfumes`, `fragrantica_exports`.
- Фото хранятся на davidsklad.ru: `/uploads/fragrantica/{thumbs,images,cards}/…` (публично, Ozon
  скачивает по ссылке). Превью списка кешируются лениво при первом показе.
- Описание: блок `relative tw-rating-card` с Фрагрантики, без хвоста «Читайте … на других языках».
- Ozon: кабинет выбирается (по умолчанию первый — Magic Stick), тип: Парфюмерная вода / Туалетная вода /
  Духи / Одеколон (категория из дерева Ozon по названию типа). Атрибуты категории приходят из Ozon;
  предзаполняются: бренд (поиск по справочнику), название, аннотация, объём, пол, ноты, «Объединить на
  одной карточке», название модели. Остальное сотрудник выбирает сам (поиск по справочникам Ozon).
- Артикул: `FR<id>-<объём>`, тестер — суффикс `T`; при занятости — `-2`, `-3`…
- Остаток 0 (дальше — обычная схема). Штрихкод генерирует Ozon (`/v1/barcode/generate`) после создания.
- Создание: `/v3/product/import` → опрос `/v1/product/import/info` → штрихкод. История в `fragrantica_exports`.
- parfumdeclaration: `POST /api/tools/perfume-card` (токен `TOOLS_TOKEN` / в davidsklad `PD_TOOLS_TOKEN`,
  `PD_TOOLS_URL`) — асинхронная задача: фото флакона → premiumBackground + enhanceSmallPhoto,
  картинка нот 1200×1600 в стиле магазина (magicstick / aura) через sharp + Pango с TTF-шрифтами
  Cormorant Garamond / Manrope и логотипом. `GET /api/tools/perfume-card/:id` — статус и JPEG в base64.

## Компоненты davidsklad
- `server/parts/02a-fragrantica-catalog-parse.js` — чистые парсеры (индекс брендов, бренд, аромат).
- `server/parts/02a-fragrantica-catalog-store.js` — таблицы, upsert, поиск, медиа.
- `server/parts/02f-fragrantica-crawler.js` — фоновый обход (worker).
- `server/parts/02d-fragrantica-catalog-routes.js` — API каталога, медиа, статус обхода.
- `server/parts/02d-fragrantica-ozon-export.js` — форма/атрибуты/подготовка фото/создание карточки.
- `frontend/src/routes/FragranticaPage.tsx` — страница (поиск, фильтры, карточка аромата, форма Ozon).
- Тесты: `test/fragrantica-parse.test.cjs`, `test/fragrantica-ozon-build.test.cjs` (фикстуры HTML).

## Ошибки
- Фрагрантика недоступна/блок — обход ставит паузу и пишет статус; страница работает с тем, что уже есть.
- parfumdeclaration недоступен — форма показывает исходное фото Фрагрантики (можно создать карточку без обработки).
- Ozon вернул ошибки импорта — показываются по полям, запись экспорта `failed`, повтор из формы.
