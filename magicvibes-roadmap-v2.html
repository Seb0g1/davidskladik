Выявленные проблемы

Баги и слабые места

⚠

Pop-up email не отправляется на сервер

PopupPromo.tsx: submit() вызывает setSent(true) без API-запроса. Email не попадает ни в какую базу — промокод выдаётся без захвата лида.

→ POST /api/shop/email-subscribe с email + source="popup" → сохранение в ShopEmailSubscriber → отправка промокода на почту.

⚠

Квиз email не отправляется

HomePage.tsx: кнопка «Отправить» в email-секции квиза — только setQuizEmailSent(true). Персонализированная рассылка по итогу квиза не работает.

→ Отправлять email + выбранную категорию квиза → персонализированная email-цепочка с подборкой.

✅

Страница 404 — пустой экран

Роутер не имел catch-all маршрута. При переходе на несуществующий URL — пустая белая страница без навигации.

→ ИСПРАВЛЕНО: добавлена NotFoundPage.tsx с premium-дизайном и path="*" в App.tsx.

⚠

Счётчик «смотрят» — скачки раз в минуту

viewerCount() в ProductPage — детерминированная функция от offerId + текущей минуты. Число резко меняется каждые 60 сек, что выглядит неестественно.

→ Интерполяция: менять на ±1 со случайным интервалом 30-90 сек, анимировать цифру.

⚠

Unboxing: только URL, не загрузка файла

Форма unboxing принимает лишь ссылку на внешнее медиа. Нужно самостоятельно куда-то залить видео и вставить ссылку — высокий барьер для обычного покупателя.

→ Drag-and-drop загрузка video/image (до 50 МБ) с прогресс-баром. Хранить в S3 или локально.

🗺

Карта мира — нет подложки, маркеры в пустоте

WorldMapPage.tsx рисует SVG-сетку и CSS-блобы вместо реальной карты мира. Маркеры стран «плывут» в тёмном фоне без географического контекста — непонятно, где что находится.

→ Подключить Natural Earth SVG-карту (public domain) или библиотеку react-simple-maps. Стилизовать в тёмной палитре с золотыми акцентами. Маркеры размещать по реальным координатам lat/lon.

🧬

AI-подбор не работает — нет данных о нотах

AI-поиск (/find) ищет по имени и описанию товара в БД — то есть по тексту «Chanel Bleu de Chanel». Понять, что этот аромат «цитрусово-древесный» из слова «тёплый, как ваниль, но не приторный» — невозможно без данных о нотах.

→ Нужен трёхуровневый план: (1) LLM-генерация нот для всех товаров сразу, (2) хранение нот в Prisma (поле fragranceNotes), (3) поиск по нотам. Fragrantica — опционально поверх.

💠

Пирамида нот — Cloudflare блокирует Fragrantica

Скрапер 02a-fragrantica-cache.js написан корректно, но fragrantica.ru защищена Cloudflare — большинство запросов возвращают 403/challenge-page. Данных почти нет → пирамида нот пуста у 95%+ товаров.

→ Краткосрочно: LLM-генерация нот по имени+бренду (Claude/GPT). Долгосрочно: Playwright headless или прокси-сервис (ScraperAPI) для обхода защиты. Добавить ручной ввод нот в admin-панели давидсклада.

Блок 04b — Критично · Фундамент

Ароматные данные — без них ни AI, ни карта, ни пирамида

Три фичи — AI-подбор, пирамида нот, карта мира — уже реализованы на уровне UI и API. Но все три работают вхолостую, потому что у товаров нет структурированных данных об ароматических нотах. Это один корневой баг с тремя симптомами. Ниже — пошаговый план устранения.

⚡

Шаг 1 — LLM-генерация нот для всего каталога

Claude или GPT знает 99% популярных ароматов из тренировочных данных. Пакетный скрипт: для каждого товара (бренд + название) запрашивает JSON с верхними/средними/базовыми нотами, аккордами, полом, сезоном. Результат: 100% каталога получает ноты за один прогон. Не идеально точно, но достаточно для AI-поиска и отображения пирамиды.

~1 день разработки Разблокирует AI + пирамиду LLM batch
🗄️

Шаг 2 — Хранение нот в Prisma (WarehouseProduct)

Добавить поле fragranceNotes Json? в модель WarehouseProduct. Структура: {"topNotes":[], "middleNotes":[], "baseNotes":[], "accords":[], "gender":"", "seasons":[]}. После этого ноты участвуют в поиске, видны в AI-запросах и синхронизируются с UI без повторных HTTP-запросов к Fragrantica.

Prisma migration Основа для поиска
🔍

Шаг 3 — AI-поиск по нотам (апгрейд /find)

После сохранения нот в БД: LLM извлекает из описания пользователя ноты и аккорды → поиск ищет товары, у которых совпадают ноты, а не только слова в названии. «Тёплый восточный с ванилью» → топ-5 по нотам: ваниль / амбра / мускус → правильные результаты. Поиск становится по-настоящему семантическим.

~0.5 дня AI-подбор заработает Upgrade
🧬

Шаг 4 — Fragrantica как верификатор (долгосрок)

Поверх LLM-нот: фоновый job обходит товары, которым >7 дней, и пытается получить данные с fragrantica.ru через Playwright headless (обходит Cloudflare) или ScraperAPI (~$30/мес). Если Fragrantica отвечает — заменяет LLM-ноты точными данными и добавляет ссылку на источник. LLM-данные остаются резервом.

Playwright + прокси Точность данных
✏️

Ручной редактор нот в davidsklad.ru

Карточка товара в складе: вкладка «Ноты аромата». Поля: верхние/средние/базовые ноты (tags), аккорды, пол, сезоны. Кнопка «Заполнить AI» — автоматически запрашивает LLM. Кнопка «Fragrantica» — ищет на сайте. Оператор может вручную уточнить. Это даёт 100% контроль над качеством данных.

~1.5 дня Контроль качества
🗺️

Карта мира — реальная SVG-подложка

Заменить CSS-блобы в WorldMapPage.tsx на Natural Earth SVG (public domain, ~200 КБ). Карта тёмная (#0a0c14), контуры стран — rgba(201,162,94,0.15), hover страны — подсветка золотом. Маркеры стоят на реальных координатах lat/lon, конвертированных в % через простую проекцию. Сразу станет красиво и понятно.

05Октябрь 2026 · Срочно

SVG-подложка карты мира в /world В работе

Встроить Natural Earth SVG (public domain) в WorldMapPage.tsx. Стиль: тёмный (#0a0c14), контуры стран rgba(201,162,94,0.15), hover — золотая подсветка страны. Маркеры переехать на lat/lon-координаты с нормализацией под проекцию SVG. Результат: карта выглядит как карта.

LLM-батч: ноты для всего каталога В работе

Скрипт в davidsklad: берёт все товары без fragranceNotes → пакетно запрашивает Claude/GPT (бренд + название → JSON с нотами). Прогресс-бар в UI. После прогона: 100% товаров имеют ноты. Пирамида нот заработает сразу.

Prisma migration: поле fragranceNotes в WarehouseProduct

Добавить fragranceNotes Json? в схему. Структура: {topNotes, middleNotes, baseNotes, accords, gender, seasons, source}. После этого данные в БД — поиск по ним, отображение в UI, синк с магазином.

AI-поиск апгрейд: поиск по нотам + аккордам

Обновить /api/shop/ai-search: LLM теперь извлекает конкретные ноты и аккорды из описания → SQL ищет по fragranceNotes JSONB. Пример: «тёплый ваниль не приторный» → WHERE fragranceNotes @> '{"accords":["vanilla"]}'. Настоящий семантический поиск.

Редактор нот в davidsklad (вкладка «Аромат»)

В карточке товара: поля top/mid/base нот, аккорды, пол, сезон. Кнопка «Заполнить AI» → автозапрос LLM. Кнопка «Fragrantica» → поиск на сайте. Ручная коррекция. Приоритет: ключевые бренды (Chanel, Dior, YSL, Tom Ford).

Fragrantica backfill: Playwright headless (долгосрок)

Фоновый worker с Playwright: обходит товары, которым >7 дней без Fragrantica-данных → headless Chrome → bypasses Cloudflare → точные ноты. Заменяет LLM-данные там, где Fragrantica отвечает. Резервный вариант — ScraperAPI ~$30/мес.
